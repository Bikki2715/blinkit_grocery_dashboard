# BlinkIT Grocery Data Analysis | Power BI

## 📊 Project Overview

if the dataset is not visible click view raw then it download and then go to the downloaded file

This project focuses on analyzing **BlinkIT grocery sales data** using **Microsoft Power BI** to identify sales patterns, outlet performance, product-level trends, and customer-related insights.

The project includes data exploration, data preparation, business analysis, and interactive data visualization through a Power BI dashboard.

The objective is to transform raw grocery sales data into meaningful insights that can support business and operational decision-making.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall grocery sales performance.
* Understand sales across different outlet types and locations.
* Identify high-performing product categories.
* Analyze the impact of item fat content on sales.
* Compare outlet sizes and their sales performance.
* Analyze outlet establishment years.
* Examine item visibility, item weight, and ratings.
* Build an interactive Power BI dashboard for business analysis.

---

## 🗂️ Dataset Information

The dataset contains **8,523 records** and **12 columns**.

### Dataset Columns

| Column                    | Description                              |
| ------------------------- | ---------------------------------------- |
| Item Fat Content          | Fat-content category of the product      |
| Item Identifier           | Unique identifier for each product       |
| Item Type                 | Category/type of grocery item            |
| Outlet Establishment Year | Year in which the outlet was established |
| Outlet Identifier         | Unique identifier of the outlet          |
| Outlet Location Type      | Location tier of the outlet              |
| Outlet Size               | Size category of the outlet              |
| Outlet Type               | Type of outlet/store                     |
| Item Visibility           | Visibility percentage of the item        |
| Item Weight               | Weight of the product                    |
| Total Sales               | Sales generated by the item              |
| Rating                    | Product rating                           |

## 🔄 Data Preparation

The raw dataset was examined and prepared before visualization.

Key data preparation activities include:

* Examining data types and column structures.
* Identifying missing values.
* Checking categorical variables.
* Reviewing sales and rating distributions.
* Preparing the dataset for Power BI analysis.
* Handling inconsistent categorical values where required.

### Data Quality Observation

The dataset contains **1,463 missing values** in the `Item Weight` column.

The `Item Fat Content` column also contains variations such as:

* `Low Fat`
* `Regular`
* `LF`
* `low fat`
* `reg`

These categorical variations should be standardized during data preparation to ensure accurate grouping and visualization.
